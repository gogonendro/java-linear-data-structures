# java-linear-data-structures
Java programs based on Stacks and Queues

## What this repository contains
This repo contains two folders:
- **Stack** - Contains 10 programs based on Stacks
- **Queue** - *programs yet to be pushed*

### Stack
This folder contains 15 Stack based programs:
1. **StackBasic**: Implements a stack and performs basic operations
2. **StackSearch**: Implements a stack and searches for a given element
3. **CharStack**: Implements a character stack and performs basic operations
4. **StackRev**: Implements a stack to reverse the accepted string
5. **PalinCheck**: Implements a stack to check whether a string is palindrome
6. **StackSum**: Implements a stack to get the sum of all the elements in it
7. **StackMax**: Implements a stack to find the largest element in it
8. **StackMin**: Implements a stack to find the smallest element in it
9. **EvenOdd**: Implements a stack to find the number of even and odd numbers
10. **DigSum**: Implements a stack to find the sum of digits of each element
