# java-linear-data-structures

Java programs based on **Linear Data Structures**, covering fundamental Class XII concepts such as stacks, queues, and linked lists

> **Note:** This repository is maintained solely for **learning and educational purposes**, as part of my study of Java Linear Data Structures

## What this repository contains

This repository contains Java programs organized into sections according to the linear data structures they demonstrate

---

## 1. Stack

Programs covering fundamental Stack concepts, operations, and applications

### Basic Operations

1. **StackBasic** — performs basic PUSH, POP, PEEK and DISPLAY operations.
2. **StackSearch** — searches for a given element and finds its position from the top.
3. **CharStack** — performs basic Stack operations using characters.

### Applications

4. **StackRev** — reverses an accepted string using Stack operations.
5. **PalinCheck** — checks whether an accepted string is a palindrome using a Stack.

### Numerical Operations

6. **StackSum** — calculates the sum of all elements present in the Stack.
7. **StackMax** — finds the largest element present in the Stack.
8. **StackMin** — finds the smallest element present in the Stack.
9. **EvenOdd** — counts the number of even and odd elements present in the Stack.
10. **DigSum** — calculates the sum of digits of each element in the Stack.

## 2. Queue

Programs covering fundamental Queue concepts, operations, and applications

### Basic Operations

1. **QueueBasic** — implements a linear Queue using an integer array with INSERT, DELETE and DISPLAY operations.
2. **QueueSearch** — searches for a given element and finds its position from the front.
3. **CharQueue** — implements a character Queue and performs basic Queue operations.

### Applications

4. **QueueRev** — displays the elements of a Queue in reverse order.
5. **QueuePalin** — uses a Queue to check whether an accepted string is a palindrome.

### Numerical Operations

6. **QueueSum** — calculates the sum of all elements present in the Queue.
7. **QueueMax** — finds the largest element present in the Queue.
8. **QueueMin** — finds the smallest element present in the Queue.
9. **QueueEvenOdd** — counts the number of even and odd elements present in the Queue.
10. **QueAvg** — calculates the average of all elements present in the Queue.

---

## 3. Linked List
Programs covering fundamental Linked List concepts, operations, and applications

### Basic Operations
1. **LinkedListBasic** — creates and displays a singly linked list.
2. **InsertBeginning** — inserts a node at the beginning of the linked list.
3. **InsertEnd** — inserts a node at the end of the linked list.
4. **InsertPosition** — inserts a node at a specified position.

### Deletion Operations
5. **DeleteBeginning** — deletes the first node of the linked list.
6. **DeleteEnd** — deletes the last node of the linked list.
7. **DeletePosition** — deletes a node at a specified position.
8. **DeleteEle** — deletes the first occurrence of a specified element.

### Searching and Analysis
9. **Search** — searches for an element and identifies its position.
10. **CountNodes** — counts the number of nodes in the linked list.
11. **MaxNode** — finds the largest element in the linked list.
12. **MinNode** — finds the smallest element in the linked list.
13. **MiddleNode** — finds the middle element, selecting the second middle for an even number of nodes.

### Reversal and Sorting
14. **Reverse** — displays the elements of the linked list in reverse order using recursion.
15. **SortList** — sorts the linked list in ascending order.
